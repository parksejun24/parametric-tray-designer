# ADR-002: 비등방성 분할보다 포함 판정 일관성을 우선한다

- 상태: 승인
- 결정일: 2026-09-22
- 범위: Phase-0 방향성 셀 알고리즘 생존성 검증

## 맥락

6개 방향성 외곽선 코퍼스에서 초기 구현은 1개만 하드 제약을 통과했다. 실패한 형상은 `SEARCH_AREA_INTERVAL_NOT_REACHED`를 반환했고, 안전 최소 면적 305 mm²의 정수배와 같은 잔차를 남겼다. 이 결과만 보면 등방성 weighted power diagram이 방향성 형상을 표현하지 못한다고 해석할 수 있었다.

독립 설계·비판 검토에서 평가 예산을 160, 480, 1600으로 늘려도 잔차가 변하지 않는 것을 확인했다. 실패 포켓의 꼭짓점은 실제로 사용 가능 영역 안에 있었지만, Clipper 정수 양자화와 offset 근사 오차보다 훨씬 엄격한 `containsRing` 기본 오차로 다시 판정되어 `containment-invalid`가 되었다. 동일한 의미의 포함 검사가 포켓 생성, 최종 불변식, 생존성 테스트에 서로 다른 수치 정책으로 중복되어 있었다.

## 결정

1. 비등방성 metric/warp는 도입하지 않는다.
2. 최종 포켓 포함 여부는 `PocketGeometryService.isContainedWithin`의 커널 교집합 면적 판정 하나를 정식 기준으로 사용한다.
3. 판정 오차는 커널 좌표 양자화와 후보 둘레로부터 계산한다.
4. 포켓 생성과 최종 불변식 검증은 같은 판정을 사용한다.
5. 테스트는 제품의 공개 결과와 같은 허용오차 계약을 검증하며, 더 엄격한 별도 기하 판정을 만들지 않는다.

## 근거

판정 일관성을 수정한 뒤 동일한 6개 코퍼스와 동일한 임계값에서 hard-valid 6/6, flow alignment 6/6, organic area-CV 6/6을 통과했다. 따라서 이번 실패는 면적 밸런서 또는 등방성 표현력의 한계가 아니라 수치 포함 분류 결함이었다.

## 기각한 대안

- 전역 affine anisotropic power metric: 현재 실패 원인을 해결하지 않으며 알고리즘·메타데이터·테스트 복잡도만 증가한다.
- 형상별 piecewise warp: 경계 불연속과 재현성 위험이 크고 현재 증거로 정당화되지 않는다.
- 임계값 완화: 승인된 품질 기준을 숨기는 방식이므로 허용하지 않는다.
- 평가 예산 증가: 10배 이상의 예산에서도 같은 잔차가 유지되어 효과가 없었다.

## 후속 조건

수정된 포함 판정 아래에서도 Phase-0 품질 게이트가 다시 실패하고, 실패가 수치 분류나 초기화·탐색 결함이 아님이 입증될 때만 비등방성 metric을 별도 ADR로 재검토한다.
